En-dimensionell layout: Elementen placeras och justeras längs en enda axel åt gången (rad -horisontallt),(kolumn-vertikalt)
Flex-selector: det är containern (föräldern) som får display: flex, vilket gör alla dess direkt underordnade element
Gap skapar ett tomrum enbart mellan de underordnade elementen, Padding: skapar ett inre avstånd mellan en containers innehåll.
Dålig feedback "Koden ser inte bra ut och din knapplayout är helt fel"                                                       Bra feedback "Knapparna hamnar utanför ramn på mindre skärmar, så lägg till flex-wrap: wrap på containern för att göra dem responsiva.
När inte flex(Grid) amvända CSS Grid i stället för flexbox när behöver styra två dimensioner samtidigit ((rad och kolumner))
